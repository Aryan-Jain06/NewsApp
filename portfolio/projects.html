Gramin Sahayak

02

HookRelay

A standalone webhook delivery service. Applications publish events to it; it signs each delivery with HMAC, retries failing endpoints with exponential backoff, and moves deliveries that run out of attempts to a dead-letter queue that can be inspected and replayed.

Load test: 10,000 events fanned out to 30,000 deliveries with none lost, including a run where the worker was killed mid-delivery.

Go Redis Streams PostgreSQL Next.js Prometheus Docker

03

SeatSync

An event ticket booking backend with a live seat map. A seat is held for five minutes by a Redis key that expires on its own, and a partial unique index in Postgres makes selling the same seat twice impossible.

Load test: 500 concurrent booking attempts across 50 seats — 50 confirmed, 450 rejected as conflicts, no double sales.
